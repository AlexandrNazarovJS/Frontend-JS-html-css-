# FreeCodeCamp Projects

A collection of projects completed as part of the **FreeCodeCamp JavaScript Algorithms and Data Structures Certification**.

These projects demonstrate practical knowledge of HTML, CSS, JavaScript, DOM manipulation, data processing, regular expressions, and API integration.

## Projects

### 1. Palindrome Checker

A web application that checks whether a given word or phrase is a palindrome.

**Technologies:** HTML, CSS, JavaScript, Regular Expressions.

**Features:**
- Checks words and phrases for palindromes.
- Ignores letter case, spaces, and punctuation.
- Normalizes input before comparison.

[View Project](./palindrome-checker)

### 2. Roman Numeral Converter

A web application that converts Arabic numerals into Roman numerals.

**Technologies:** HTML, CSS, JavaScript.

**Features:**
- Converts numbers from 1 to 3999.
- Handles invalid input and numerical boundaries.
- Uses Roman numeral conversion logic.

[View Project](./roman-numeral-converter)

### 3. Telephone Number Validator

A web application that validates US phone numbers using different formatting patterns.

**Technologies:** HTML, CSS, JavaScript, Regular Expressions.

**Features:**
- Validates US phone number formats.
- Checks country codes and area codes.
- Displays validation results.
- Provides an option to clear results.

[View Project](./telephone-number-validator)

### 4. Cash Register

A cash register application that calculates the correct change based on the purchase price, customer payment, and available cash in the drawer.

**Technologies:** HTML, CSS, JavaScript.

**Features:**
- Calculates the change due.
- Handles different currency denominations.
- Determines whether the cash drawer has sufficient funds.
- Supports OPEN, CLOSED, and INSUFFICIENT_FUNDS statuses.

[View Project](./cash-register)

### 5. RPG Creature Search App

A web application that allows users to search for RPG creatures by name or ID using the FreeCodeCamp RPG Creature API.

**Technologies:** HTML, CSS, JavaScript, Fetch API.

**Features:**
- Searches creatures by name or ID.
- Retrieves creature data from an external API.
- Displays creature statistics and types.
- Handles invalid search queries.

[View Project](./rpg-creature-search)

# Проєкти FreeCodeCamp

Збірка проєктів, виконаних у межах сертифікаційної програми **FreeCodeCamp JavaScript Algorithms and Data Structures Certification**.

Проєкти демонструють практичні навички роботи з HTML, CSS, JavaScript, DOM, обробкою даних, регулярними виразами та інтеграцією API.

## Проєкти

### 1. Palindrome Checker

Вебзастосунок для перевірки того, чи є введене слово або фраза паліндромом.

**Технології:** HTML, CSS, JavaScript, регулярні вирази.

**Можливості:**
- Перевірка слів і фраз на паліндром.
- Ігнорування регістру літер, пробілів і розділових знаків.
- Нормалізація введеного тексту перед перевіркою.

[Переглянути проєкт](./palindrome-checker)

### 2. Roman Numeral Converter

Вебзастосунок для перетворення арабських чисел на римські цифри.

**Технології:** HTML, CSS, JavaScript.

**Можливості:**
- Перетворення чисел від 1 до 3999.
- Перевірка некоректного введення та допустимих числових меж.
- Реалізація логіки конвертації римських чисел.

[Переглянути проєкт](./roman-numeral-converter)

### 3. Telephone Number Validator

Вебзастосунок для перевірки телефонних номерів США з підтримкою різних форматів запису.

**Технології:** HTML, CSS, JavaScript, регулярні вирази.

**Можливості:**
- Перевірка різних форматів телефонних номерів США.
- Перевірка коду країни та телефонного коду регіону.
- Відображення результатів перевірки.
- Можливість очищення результатів.

[Переглянути проєкт](./telephone-number-validator)

### 4. Cash Register

Вебзастосунок касового апарата, який розраховує решту на основі вартості покупки, отриманої оплати та наявних коштів у касі.

**Технології:** HTML, CSS, JavaScript.

**Можливості:**
- Розрахунок решти.
- Робота з різними номіналами грошових одиниць.
- Перевірка достатності коштів у касі.
- Обробка статусів OPEN, CLOSED та INSUFFICIENT_FUNDS.

[Переглянути проєкт](./cash-register)

### 5. RPG Creature Search App

Вебзастосунок для пошуку RPG-істот за назвою або ID з використанням FreeCodeCamp RPG Creature API.

**Технології:** HTML, CSS, JavaScript, Fetch API.

**Можливості:**
- Пошук істот за назвою або ID.
- Отримання даних із зовнішнього API.
- Відображення характеристик і типів істот.
- Обробка некоректних пошукових запитів.

[Переглянути проєкт](./rpg-creature-search)
